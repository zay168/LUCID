## 🌌 Qu'est-ce que LUCID ?

**LUCID** est une application de santé mentale nouvelle génération qui transforme comment vous gérez l'anxiété.

> L'anxiété nous fait imaginer des scénarios catastrophiques qui ne se réalisent **jamais**. LUCID vous aide à le prouver.

### Comment ça marche ?

```
😰 Anxiété  →  📝 Capture  →  🔒 Verrouillage  →  ⏰ Vérification  →  📊 Lucidité  →  😌 Sérénité
```

1. **📝 Capturez** vos inquiétudes dans un moment d'anxiété
2. **🔒 Verrouillez** ces pensées dans un coffre-fort virtuel
3. **⏰ Programmez** une date de vérification future
4. **✅ Vérifiez** si vos peurs se sont réalisées
5. **📊 Découvrez** votre **Taux de Lucidité** — le % d'inquiétudes non réalisées
